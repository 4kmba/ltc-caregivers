# WhyTree — 백민경

- 작성: 백민경, 2026-10-29
- 원본: `WhyTree_백민경.pptx`
- 슬라이드 제목: 장기요양 가족 보호자의 돌봄 결정을 돕는 AI 서비스

## 읽는 법

- 들여쓰기 한 단계 위가 why, 아래가 그 why를 이루는 how다.
- `(씨앗)`: 먼저 생각난 일
- `(새로 찾은 일)`: 지금은 하지 않지만 WhyTree를 그리며 새로 찾은 일. 슬라이드에서 점선 상자
- `(부가적인 why)`: 슬라이드에서 점선 화살표. 표시가 없으면 실선 화살표(가장 중요한 why)

## 트리

- 보호자의 심적·물적 돌봄 부담 덜기
  - 정보를 찾고 판단하는 데 드는 시간을 줄여 실제 돌봄에 집중하기
    - 가족 간 돌봄 분담표 공유 (새로 찾은 일) (부가적인 why)
    - AI가 먼저 묻는 상황 인터뷰 (새로 찾은 일) (부가적인 why)
  - 우리 가족의 돌봄 상황에 맞는 판단하기
    - 질문을 몰라도 답 찾기
      - 질문을 제안해주는 질문카드 (씨앗)
      - AI가 먼저 묻는 상황 인터뷰 (새로 찾은 일)
      - 맞춤형 돌봄 지식 ChatGPT (씨앗) (부가적인 why)
    - 상황이 바뀔 때 제때 움직이기
      - 위기 시나리오별 액션 플랜 (씨앗)
      - 중요 돌봄 일정/납부 리마인더 (씨앗)
      - 상태 변화 신호 점검표 (새로 찾은 일)
    - 맞춤형 돌봄 지식 ChatGPT (씨앗)
  - 흩어진 돌봄 정보를 믿고 활용하기
    - 제도·지원 변화 제때 알기
      - 최신 제도 변경/지원 정보 뉴스피드 (씨앗)
    - 답마다 출처·날짜 표시 (새로 찾은 일)
