# WhyTree: 김영균

- 날짜: 2026-10-28
- 출발점: AI Care Decision Assistant가 하는 일 다섯 가지(씨앗)
- 원본: `WhyTree_김영균.pptx` 슬라이드와 같은 나무를 글로 옮겼다.

## 읽는 법

- 위가 목적(why), 아래로 들여 쓴 줄이 그 목적을 이루는 방법(how)이다.
- `[씨앗]`은 제품이 지금 하는 일, `[새 방법]`은 How Down으로 새로 찾은 방법(슬라이드의 점선 상자)이다.
- 한 칸이 여러 목적을 도우면 가장 중요한 why(실선) 아래에 두고, 부가적인 why(점선)는 `점선 →`으로 적는다.

## 나무

- 필요한 케어를 제때 제공하기
  - 전문 인력 상담 `[새 방법]`
  - 돌봄 제공 기관 `[새 방법]` (점선 → 죄책감 없이 나를 돌볼 시간 갖기)
  - (점선) 내 결정에 확신 갖기: 아래 "죄책감 없이 나를 돌볼 시간 갖기" 쪽에 있음
  - (점선) 합리적인 결정: 아래 "내 결정에 확신 갖기" 밑에 있음

- 죄책감 없이 나를 돌볼 시간 갖기
  - 내 결정에 확신 갖기 (점선 → 필요한 케어를 제때 제공하기)
    - 가족의 반대·비판에 흔들리지 않기
    - 합리적인 결정 (점선 → 필요한 케어를 제때 제공하기)
      - 무엇을 언제 결정할지 알기
        - 한눈에 보기 쉽게 보여 주기 `[씨앗]`
        - 대상자 맞춤 할 일 목록 `[새 방법]`
      - 정확한 정보 얻기
        - 확실한 근거로 정보 정리하기 `[씨앗]`
        - (점선) AI 통합 검색·요약: 아래 "일일이 찾아보는 수고 덜기" 밑에 있음
      - 흩어진 정보 모아 주기 `[씨앗]` (점선 → 죄책감 덜기, 일일이 찾아보는 수고 덜기)
      - 놓친 정보까지 말하기
        - (점선) 음성으로 입력·답변 받기: 아래 "바쁜 중에도 쉽게 묻기" 밑에 있음
  - 감정 소진 줄이기
    - 죄책감 덜기
      - (점선) 흩어진 정보 모아 주기: 위 "합리적인 결정" 밑에 있음
    - 일일이 찾아보는 수고 덜기
      - 돌봄 질문에 대화로 답하기 `[씨앗]`
      - AI 통합 검색·요약 `[새 방법]` (점선 → 정확한 정보 얻기)
      - 바쁜 중에도 쉽게 묻기
        - 음성으로 입력·답변 받기 `[씨앗]` (점선 → 놓친 정보까지 말하기)
      - (점선) 흩어진 정보 모아 주기: 위 "합리적인 결정" 밑에 있음
  - 가족 간 역할 분담 `[새 방법]`
  - (점선) 돌봄 제공 기관: 위 "필요한 케어를 제때 제공하기" 밑에 있음

## 씨앗 다섯 가지

1. 돌봄 질문에 대화로 답하기
2. 확실한 근거로 정보 정리하기
3. 한눈에 보기 쉽게 보여 주기
4. 음성으로 입력·답변 받기
5. 흩어진 정보 모아 주기
