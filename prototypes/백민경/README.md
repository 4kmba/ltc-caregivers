# 위기 시나리오별 액션 플랜 (P0 프로토타입)

스펙: [docs/specs/백민경-actionplan.md](../../docs/specs/백민경-actionplan.md)

상황이 바뀐 순간(치매 증상 악화, 갑작스러운 낙상, 주 보호자가 돌볼 수 없게 됨)에 주 보호자가 카드 몇 번만 눌러 선택지를 비교하고, 고른 선택지의 할 일을 한 장으로 보는 휴대폰용 웹 페이지입니다. P0에는 AI가 없고, 서버나 API 키도 필요 없습니다.

## 실행

Node만 있으면 됩니다. 저장소 루트에서 다음 명령을 실행하고 브라우저에서 `http://localhost:5173`을 엽니다.

```
node prototypes/백민경/serve.js
```

`index.html`을 파일로 바로 열어도 대부분의 브라우저에서 동작합니다. 다만 가족 정보 저장은 브라우저에 따라 막힐 수 있습니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `data.js` | 상황, 꼬리 질문, 시나리오, 액션 플랜, 연락처, 출처. 내용은 여기서만 고친다 |
| `app.js` | 화면 흐름: 처음 화면 → 꼬리 질문 → 시나리오 카드 → 액션 플랜 |
| `style.css` | 휴대폰 화면에 맞춘 모양 |
| `serve.js` | 이 폴더만 내주는 작은 로컬 서버 |

## 직접 해 볼 점검

스펙 8절의 점검 3개를 그대로 따릅니다.

1. "갑작스러운 낙상" → 꼬리 질문이 바로 나온다. "기타/잘 모르겠어요" → 공통 기본 플랜이 바로 나온다. 어느 화면에도 119 안내가 없다.
2. "치매 증상 악화" → 성격·행동 / 있었다 / 없다 / 잘 모르겠어요 / 잘 모르겠어요 → 요양원 카드에 "잘 맞을 수 있음"과 이유 → 카드를 누르면 액션 플랜 6개 구역이 나오고, "확인할 것"에 두 질문이 보인다.
3. 가족 정보에 "따로 산다" 저장 → 새로고침 → "주 보호자가 돌볼 수 없게 됨"에서 동거 여부를 묻지 않는다 → "모든 기록 지우기" 뒤에는 가족 정보가 비어 있다.

## 남은 일

- `data.js`의 `SOURCES`에 있는 공식 사이트에서 연락처와 제도 안내를 확인한 뒤 `verifiedAt`에 날짜를 적는다. 지금은 화면에 "확인 전"으로 나온다.
