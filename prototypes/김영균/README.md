# 맞춤 돌봄 할 일 목록 (김영균)

보호자가 질문 8개와 보충 질문 몇 개에 답하면, 지금 돌봄 단계에 맞는 할 일 6개 안팎을 "이번 주, 이번 달, 미리 알아둘 것"으로 나눠, 인덱스 탭이 달린 돌봄 수첩처럼 보여 주는 모바일 웹입니다. 할 일마다 연락처, 출처, 물어볼 질문과 답이 붙습니다. 기준 스펙은 [`docs/specs/김영균-care-todo.md`](../../docs/specs/김영균-care-todo.md)입니다.

2026-11-07부터 **서버와 AI 없이 브라우저에서만 돕니다.** 수업 프로젝트는 끝났지만 인터뷰에 응해 준 보호자분들께 링크로 나눠 드리려고 바꿨습니다. AI가 하던 일은 이렇게 바뀌었습니다.

| AI가 하던 일 | 지금 |
|---|---|
| 보충 질문 만들기 | 답에 따라 미리 정해 둔 선택형 질문 0～3개와 "요즘 가장 걱정되는 일" 한 줄 |
| 카드 고르고 이유 쓰기 | 규칙이 고르고, 어떤 답 때문에 넣었는지 보여 줌. 안 맞으면 보호자가 숨기거나 다른 할 일을 넣을 수 있음 |
| 질문에 상황 맞춰 답하기 | 카드마다 공식 자료로 확인한 질문과 답을 4개 이상 미리 써 둠 |

AI를 쓰던 HW6 버전은 커밋 `61e34c3`에 남아 있습니다.

## 공유하기

`public/` 폴더가 화면 전부입니다. 이 폴더를 GitHub Pages 같은 정적 호스팅에 올리면 링크 하나로 열립니다. 보호자의 답과 체크는 그 휴대폰의 브라우저에만 저장되고 어디로도 보내지 않습니다.

## 로컬에서 보기

Node 22.9 이상이 필요하고, 설치할 패키지는 없습니다.

```bash
cd prototypes/김영균
npm start
```

브라우저에서 <http://localhost:3000>을 엽니다. 휴대폰 화면 크기에 맞춰 만들었습니다.

## 점검

```bash
npm test
```

카드 형식(질문 4개 이상, 출처, 반각 물결표 없음), 조건 문법, 보충 질문, 숨기기와 더 넣기, 응급 키워드, 사례 15건을 확인합니다.

```bash
npm run check:cases
```

인터뷰 요약 5건(C2, C3, C5, C6, H1)과 일부러 까다롭게 만든 상황 10건(E1～E10)을 넣고, 사례마다 들어가야 할 카드와 나오면 안 되는 카드를 확인하며 목록과 "왜 넣었는지"를 출력합니다.

### 2026-11-07 점검

AI를 끄고 예전 규칙으로 15건을 돌리자, 단계는 모두 맞았지만 상황에 맞지 않는 카드가 반복해서 나왔습니다. 고친 뒤에는 15건 모두 통과합니다.

| 나온 문제 | 사례 | 고친 방법 |
|---|---|---|
| 이미 쓰는 서비스를 다시 고르라는 카드 | 6건 | 방문요양·주야간보호·요양원을 이미 쓰면 빼고, 대신 "지금 받는 서비스가 상황에 맞는지 점검하기" 카드를 새로 만듦 |
| 요양원 입소자에게 복지용구, 입소 서류, 단기보호 카드 | E1, E5 | 요양원에 계시면 집과 입소 준비 카드를 빼고, "요양원에서 지내시는 모습을 정기적으로 확인하기" 카드를 새로 만듦 |
| 뇌졸중인데 1번을 "잘 모르겠어요"로 고르면 치매 검사 카드 | E2 | 치매 검사 카드는 1번이 치매 의심이거나, 대화가 엉뚱하거나, 진단을 모를 때만 나오게 함 |
| 요양병원에 계속 계실 분께 퇴원 준비 카드 | E7 | 입원 중이면 "병원에 얼마나 더 계실지"를 묻고, 계속 계시면 퇴원·집 정리 카드를 뺌 |
| 꼭 필요한 카드가 밀려남 | C2, C6 | 보충 질문과 걱정 칸의 답과 맞는 카드를 앞에 둠 |

## 구조

| 경로 | 하는 일 |
|---|---|
| `public/index.html`, `app.js`, `style.css` | 화면. 답, 목록, 체크, 글자 크기 설정은 브라우저 `localStorage`에만 저장 |
| `public/logic.js` | 단계 정하기, 카드 조건 맞추기, 목록 고르기, 이유 만들기, 응급 키워드 확인 |
| `public/data/questions.json` | 고정 질문 8개 |
| `public/data/followups.json` | 보충 질문 3개, 걱정 칸, 걱정 낱말과 관련 카드 |
| `public/data/cards.json` | 할 일 카드 45장, 카드마다 질문과 답, 출처 목록 |
| `server.mjs` | 로컬 미리 보기용 정적 파일 서버 |
| `scripts/run-cases.mjs` | 사례 15건 점검 |
| `test/` | 자동 테스트 |

## 한계

- 카드는 공개 자료를 바탕으로 김영균이 혼자 썼고, 2026-10-29과 2026-11-07에 법령·고시 원문과 공단, 정부24, 보건복지부 안내로 사실을 확인했습니다. 팀원 검토는 받지 않았습니다.
- 제도는 해마다 바뀝니다. 화면에 "2026년 11월에 확인한 내용"이라고 적어 두었지만, 프로젝트가 끝나 카드를 계속 고칠 사람이 없습니다. 보건복지부는 요양병원 간병비를 2027년 상반기부터 급여화할 계획이라고 밝혔으므로, 그때 간병비 카드(S3-04, S3-08)가 낡은 정보가 됩니다.
- 사례 점검의 답은 인터뷰 요약과 김영균이 만든 상황을 보고 고른 것이라, 실제 보호자가 직접 답한 결과가 아닙니다.
- 응급 신호와 걱정 주제는 낱말로만 찾아서, 목록에 없는 표현은 놓칠 수 있습니다.
