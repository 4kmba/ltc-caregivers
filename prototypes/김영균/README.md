# 맞춤 돌봄 할 일 목록 프로토타입 (김영균)

보호자가 질문 8개와 보충 질문 몇 개에 답하면, 지금 돌봄 단계에 맞는 할 일 5～7개를 "이번 주, 이번 달, 미리 알아둘 것"으로 나눠, 인덱스 탭이 달린 돌봄 수첩처럼 보여 주는 모바일 웹입니다. 맨 위에는 지금 먼저 할 일 하나를 보여 주고, "이번 주", "이번 달", "알아두기" 탭에 몇 개를 끝냈는지 표시합니다. 탭을 누르면 그 장만 보이고, 이번 주를 다 끝내면 이번 달 장이 열립니다. 상황이 바뀌면 지난 답을 고쳐 새 목록을 받을 수 있고, 이미 끝낸 일의 체크는 그대로 남습니다. 기준 스펙은 [`docs/specs/김영균-care-todo.md`](../../docs/specs/김영균-care-todo.md)이고, HW6 Part 3 과제로 김영균이 혼자 만들었습니다.

## 실행

Node 22.9 이상이 필요합니다.

```bash
cd prototypes/김영균
npm install
npm start
```

브라우저에서 <http://localhost:3000>을 엽니다. 휴대폰 화면 크기에 맞춰 만들었습니다.

AI를 쓰려면 이 폴더에 `.env`를 만들고 `.env.example`처럼 `ANTHROPIC_API_KEY=` 뒤에 키를 적습니다. `.env`는 `.gitignore`에 있어 올라가지 않습니다. 키가 없으면 AI 없이 규칙 기본 목록으로만 동작하고, 서버를 켤 때 "AI 꺼짐"이 표시됩니다.

## 점검

```bash
npm test
```

카드 형식, 규칙 기본 목록, 응급 키워드, AI 응답 검증, AI 없는 서버 동작을 확인하는 자동 테스트 13개입니다.

```bash
npm run check:cases
```

스펙의 손 점검 1번입니다. 인터뷰 요약 5건(C2, C3, C5, C6, H1)의 상황을 비식별한 답으로 넣고, 단계가 맞는지, 모든 할 일에 출처가 있는지, 인터뷰에서 막혔다고 말한 일이 목록에 들어가는지 출력합니다.

### 2026-10-29에 직접 돌린 결과

| 점검 | 결과 |
|---|---|
| 1. 인터뷰 사례 5건 (AI 켬) | 5건 모두 단계가 맞고 모든 할 일에 출처가 있음. 막힌 일에 맞는 카드는 두 번 돌려 10장 중 10장, 9장이 들어감(두 번째에 H1의 낙상 신호 카드가 빠짐). AI가 고르는 카드는 돌릴 때마다 조금씩 다름. 목록 한 번에 6～8초 |
| 1. 인터뷰 사례 5건 (AI 끔) | 단계와 출처는 같음. 막힌 일 카드 10장 가운데 9장이 들어감(C2의 산정특례 카드가 빠짐) |
| 2. AI 없이 돌리기 | 키 없이 켠 서버에서 규칙 기본 목록, "지금은 AI 설명 없이 기본 목록을 보여 드려요", 공단 1577-1000이 나옴. 질문을 누르면 카드 원문이 나옴 |
| 3. 응급 신호 넣기 | 보충 질문에 "어제부터 불러도 대답이 없어요"를 입력하자 0.1초 만에 119 안내가 목록보다 먼저 뜸. 안내를 닫아야 목록이 보임. 다시 열면 전체 화면 대신 수첩 맨 위에 119 줄이 남음 |
| 4. 다시 받기와 큰 글씨 | 세 개를 체크한 뒤 답 하나만 바꿔 다시 받자 "완료한 일 3개는 그대로 두었어요"가 뜸. 단계를 바꿔 목록이 모두 바뀌면 줄마다 표시하지 않고 한 줄로 알림. 글자 크게를 켜고 375px 너비에서 가로로 넘치는 곳 없음 |
| 색 대비 | 밝은 화면과 어두운 화면의 글자·배경 조합이 모두 4.5:1 이상(가장 낮은 것 5.05:1) |

점검하면서 고친 것은 스펙 끝의 "변경 기록"에 적었습니다. 규칙 기본 목록이 단계와 등급만 보던 것을 카드 조건까지 보게 바꿨고, AI가 질문의 답에서 위급도를 판단하지 않게 했습니다.

## 구조

| 경로 | 하는 일 |
|---|---|
| `data/questions.json` | 고정 질문 8개 |
| `data/cards.json` | 할 일 카드 43장과 출처 목록 |
| `src/rules.mjs` | 단계 정하기, 후보 카드 거르기, 규칙 기본 목록, 응급 키워드 확인 |
| `src/ai.mjs` | Claude Sonnet 5.5 호출 세 가지(보충 질문, 카드 고르기, 답 풀어 쓰기). 15초 제한, 실패하면 `null` |
| `server.mjs` | 화면 파일과 API(`/api/questions`, `/api/followups`, `/api/emergency`, `/api/plan`, `/api/answer`) |
| `public/` | 화면. 체크, 목록, 답, 글자 크기 설정은 브라우저 `localStorage`에만 저장. 휴대폰이 어두운 화면이면 자동으로 어둡게 보임 |
| `scripts/run-cases.mjs` | 인터뷰 사례 점검 |
| `test/` | 자동 테스트 |

## 한계

- 카드는 공개 자료를 바탕으로 김영균이 혼자 썼고, 2026-10-29에 법령·고시 원문과 정부24, 보건복지부 안내로 사실을 확인했습니다. 이때 치매상담콜센터 운영 시간(24시간이 아니라 매일 오전 7시～오후 10시), 장기요양 가족휴가제의 이름과 대상, 단기보호 일수, 본인부담 면제 대상을 고쳤습니다. 팀원 검토는 아직 받지 않았습니다.
- 출처 링크는 대부분 기관 누리집이나 법령 첫 화면이라, 카드의 문장이 그 안의 어느 조문에 있는지까지는 화면에 보여 주지 않습니다.
- 보건복지부가 요양병원 간병비를 2027년 상반기부터 급여화할 계획이라고 밝혔습니다(2026-07-28 보도자료). 그때 간병비 카드(S3-04, S3-08)를 다시 확인해야 합니다.
- 인터뷰 사례 점검은 인터뷰 요약을 보고 김영균이 답을 고른 것이라, 실제 보호자가 직접 답한 결과가 아닙니다.
- 응급 신호는 키워드로만 찾아서, 목록에 없는 표현은 놓칠 수 있습니다.
