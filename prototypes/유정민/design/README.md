스펙의 돌봄 AI 프로토타입에 붙일 이름, 색, 화면 시안이다. 아직 프로토타입 코드(`public/style.css`)와 스펙 제목에는 반영하지 않았다.

## 이름: 돌봄 수첩

보호자가 질문에 고르기로 답하면 돌봄 방식을 정리한 한 장이 나온다. 이 한 장을 수첩 한 페이지로 본다. 상황이 바뀌어 다시 정리하면 수첩에 새 장을 쓰는 셈이라, 상황이 바뀔 때마다 선택지를 다시 정리한다는 제품 정의와 이름이 맞는다.

이름에 "AI"를 넣지 않았다. 인터뷰에서 AI를 믿지 않거나 쓰지 않는 사람이 4명이었기 때문이다. "추천"이나 "결정"도 넣지 않았다. 이 서비스는 돌봄 방식을 비교만 하고 하나를 골라 주지 않는다(스펙 6절 범위 밖 1번).

이 이름을 팀 서비스 전체에 쓸지는 팀이 정한다.

## 색

노랑 수첩 표지에 먹색 잉크로 적는 모습을 기준으로 삼았다. 노랑은 흰 바탕 위 글자색으로 쓰면 대비가 약 1.5:1이라 읽히지 않는다. 그래서 노랑은 표지와 형광펜, 버튼 바탕에만 쓰고 글자는 먹색으로 쓴다.

| 이름 | 색상 코드 | 쓰는 곳 | 대비 |
|---|---|---|---|
| 개나리 노랑 | `#F7C948` | 키 컬러. 상단 바, 버튼 바탕, 고른 답 | 먹색 글자 9.1:1 |
| 크림 속지 | `#FFFBEA` | 화면 바탕 | 먹색 글자 13.8:1 |
| 속지 줄 | `#E9DFC4` | 결과 한 장의 가로줄, 칸 테두리 | 장식용. 글자에 쓰지 않는다 |
| 먹색 잉크 | `#2B2A26` | 본문, 제목, 버튼 글자 | 크림 바탕 13.8:1 |
| 연한 잉크 | `#5C574C` | 보조 설명, 날짜 | 크림 바탕 6.9:1 |
| 형광펜 | `#FFE98A` | "지금 결정할 것" 한 줄에만 | 먹색 글자 11.8:1 |
| 진한 겨자 | `#7A5C00` | 링크 글자. 밑줄과 함께 쓴다 | 크림 바탕 6.0:1 |
| 응급 빨강 | `#B42318` | 응급 안내 화면에만 | 흰 글자 6.6:1 |

대비는 WCAG 기준으로 계산했고, 본문 글자는 모두 4.5:1을 넘는다.

쓰지 않는 색도 정했다.

- **녹색과 주황은 쓰지 않는다.**
- **파랑을 키 컬러로 쓰지 않는다.** 국민건강보험공단, 복지로 같은 공공 기관 사이트가 대부분 파랑이다. 한 장 안에 공단 링크를 함께 보여 주므로, 공식 기관 화면으로 오해받지 않게 색으로 구분한다.
- **빨강은 응급 안내에만 쓴다.** 다른 곳에 쓰면 응급 안내가 덜 눈에 띈다.

## 수첩처럼 보이게 하는 장치

| 장치 | 화면 | 하는 일 |
|---|---|---|
| 노랑 표지와 스프링 고리 | 모든 화면 위쪽 | 서비스 이름과 진행 단계를 보여 준다 |
| 줄 쳐진 속지와 날짜 | 결과 한 장 | 언제, 어떤 상황에서 정리했는지 적는다 |
| 형광펜 | 결과 한 장의 "지금 결정할 것" | 가장 먼저 읽을 한 줄을 표시한다 |
| 마스킹 테이프 메모 | 결과 한 장 맨 위 | "참고용 정리입니다. 결정은 가족과 의료진이 함께 하세요." 고정 문구를 붙인다 |
| 체크 칸 | 질문 화면의 답, 의료진에게 물어볼 질문 | 고른 답은 노랑으로 채우고 체크 표시를 한다 |
| 새 장 쓰기 | 결과 한 장 아래 버튼 | 상황이 바뀌면 다시 정리한다(스펙 P1) |

## 글꼴과 크기

- 제목: Gaegu(손글씨). 제목에만 쓴다. 본문에 쓰면 나이 든 보호자가 읽기 어렵다.
- 본문: Noto Sans KR. 본문 15～18px, 질문 제목 24px.
- 버튼과 답 칸은 높이 56px 이상으로 만들어 손가락으로 누르기 쉽게 한다.

## 화면 시안

휴대폰 화면(390px 너비) 기준이다. 시안 캔버스에서 볼 수 있다.

1. **색 견본.** 위 색 8개와 버튼, 형광펜, 링크, 테이프 메모, 쓰지 않는 색을 함께 놓았다.
2. **질문 화면.** 질문 1 "어떤 상황인가요?"에서 "낙상"을 고른 상태다.
3. **결과 한 장.** 낙상 상황을 가정한 예시다. 돌봄 방식 3개를 비교하고, 지원과 연락처, 의료진에게 물어볼 질문을 보여 준다.
4. **응급 안내.** 응급 확인에서 "예"를 눌렀을 때 나오는 화면이다. 119 전화 버튼만 빨강이다.

결과 한 장의 예시 문구는 `sources.json`에서 확인한 내용만 썼다. 본인부담 기준(재가급여 15%, 시설급여 20%)은 5번 항목에서 가져왔다. 지원과 연락처는 1번(노인장기요양보험 홈페이지·고객센터), 12번(낙상예방 재가환경지원 시범사업), 16번(치매안심센터·보건소 찾기) 항목의 이름, 링크, 번호를 그대로 썼다. 돌봄 방식의 장점과 단점 문구는 화면 모양을 보이려고 쓴 예시이고, 실제 화면에서는 AI가 채운다.

## 지킬 것

- **비교 카드 2～3개는 모두 같은 색으로 둔다.** 카드 하나만 강조하면 그 방식을 추천하는 것처럼 읽힌다. 장점과 단점도 초록과 빨강으로 나누지 않고 칸 제목으로 구분한다.
- **형광펜은 "지금 결정할 것"에만 칠한다.** 여러 곳에 칠하면 무엇을 먼저 읽을지 흐려진다.
- **노랑을 글자색으로 쓰지 않는다.**
