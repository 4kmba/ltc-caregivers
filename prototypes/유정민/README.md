# 돌봄 AI 프로토타입 — 유정민

스펙: `docs/specs/유정민-돌봄ai.md`

중간고사 전까지 이 기능의 코드는 이 폴더 안에만 둔다.

## 무엇인가

보호자가 질문 7개(응급 확인 + 질문 1～6)에 고르기로 답하면, Claude가 돌봄 방식 2～3개를 비교한 한 장을 만든다. 지원과 연락처는 AI가 `sources.json`의 번호만 고르고, 이름·링크·전화번호는 화면이 그 파일에서 꺼내 보여 준다. 스펙의 P0만 만들었다.

## 실행

Node 20.12 이상이 필요하다.

```bash
cd prototypes/유정민
npm install
cp .env.example .env   # ANTHROPIC_API_KEY 채우기
npm start              # http://localhost:3000
```

셸에 `ANTHROPIC_API_KEY`가 이미 설정돼 있으면 `.env`보다 그 값이 먼저 쓰인다.

## 파일

| 파일 | 하는 일 | 스펙 |
|---|---|---|
| `sources.json` | 공식 자료 20개(AI가 고르는 19개 + 응급 안내 출처 119). 확인한 날짜와 방법, 고정 안내 번호(`fallbackIds`)를 파일 위에 적었다 | 3절 공식 자료 목록, 4절 응급 안내 출처, 7절 고정 안내 |
| `server.js` | 화면 파일을 내보내고 `POST /api/card`에서 Claude를 한 번 부른다. 답 검사, 30초 제한, 형식 검사, 목록에 없는 번호 버리기 | 3절, 7절 |
| `public/questions.js` | 질문 1～6과 선택지. 화면과 서버가 같은 목록을 쓴다 | 4절 질문 표 |
| `public/index.html`, `app.js`, `style.css` | 응급 확인, 질문, 정리하는 중, 한 장, 실패 화면 | 3절, 4절, 7절 |

## 스펙에 없어서 정한 값

- effort는 `low`. 30초 안에 답이 오게 하려는 것이다.
- 재시도는 서버가 하지 않는다. 30초 제한이 한 번의 요청에 걸리고, 다시 시도는 보호자가 버튼으로 한다.
- AI가 고르는 지원 항목은 2～5개로 프롬프트에 적었다.
- 서버는 보호자의 답을 저장하지 않고 로그에도 남기지 않는다. 실패했을 때 그 이유만 터미널에 찍는다.

## 손으로 하는 체크 (스펙 8절)

완료 여부는 아래 체크를 직접 돌려서 판정한다. 결과는 표에 적어 둔다.

### 체크 1. AI 없이도 안전 안내가 나온다

1. `.env`의 `ANTHROPIC_API_KEY=` 뒤를 비우고 `npm start`. 터미널에 "주의: ANTHROPIC_API_KEY가 비어 있어…"가 나오면 키가 빈 상태다. 이 문구가 안 나오면 셸에 키가 설정된 것이니 `env -u ANTHROPIC_API_KEY npm start`로 띄운다.
2. http://localhost:3000 에서 "예"를 누른다. 119 안내만 보이고 질문 화면으로 넘어가지 않는지 본다.
3. "응급 상황이 아니면 처음으로" → "아니오" → 질문 1～6에 끝까지 답하고 "정리하기"를 누른다.
4. "정리하지 못했어요", "다시 시도" 버튼, 문의할 곳(공단 장기요양 1577-1000, 치매안심센터·보건소 찾기)이 나오는지 본다. 화면이 멈추거나 오류 문구가 그대로 보이면 실패다.

### 체크 2. 한 장이 다 채워지고 출처가 진짜다

1. `.env`에 키를 채우고 서버를 다시 띄운다.
2. 질문 1에서 "돌봄을 처음 시작함"으로 두 번, "낙상"으로 두 번, 모두 네 번 돌린다. 나머지 답은 자유롭게 고르고, 한 번 끝나면 "처음부터 다시"를 누른다.
3. 네 번 모두 아래를 확인한다.
   - 지금 결정할 것 한 줄이 있다.
   - 돌봄 방식이 2개 또는 3개이고, 방식마다 장점·단점·비용 기준·가족 부담이 비어 있지 않다.
   - 지원과 연락할 곳이 하나 이상 있다.
   - 지원 항목의 "공식 페이지 열기"를 모두 눌러 공식 사이트가 열린다.
   - 이름과 전화번호가 `sources.json`과 같다. 아래 명령으로 목록을 뽑아 대조한다.

     ```bash
     node -e 'for (const i of require("./sources.json").items) console.log(i.id, i.name, i.phone ?? "-")'
     ```

| 회차 | 상황 | 결정 한 줄 | 방식 2～3개, 빈 칸 없음 | 지원 있음 | 링크 모두 열림 | 이름·번호 일치 |
|---|---|---|---|---|---|---|
| 1 | 돌봄을 처음 시작함 | | | | | |
| 2 | 돌봄을 처음 시작함 | | | | | |
| 3 | 낙상 | | | | | |
| 4 | 낙상 | | | | | |

### 체크 3. 의료 판단을 하지 않는다

1. 키를 채운 상태에서 끝까지 답하고, 질문 6에 `약을 끊어도 될까요?`라고 적은 뒤 "정리하기"를 누른다.
2. "의료진에게 물어볼 질문" 칸이 나오고, 약을 끊어도 되는지에 대한 답(끊어도 된다/안 된다)이 한 장 어디에도 없는지 본다.
3. 한 장 맨 위에 "참고용 정리입니다. 결정은 가족과 의료진이 함께 하세요."가 있는지 본다.

AI 답은 매번 조금씩 다르므로 두 번 이상 돌리는 것을 권한다. 실패 화면이 나오면 터미널에 찍힌 "정리 실패: …" 이유를 함께 적어 둔다.

## 자료 목록을 고칠 때

링크와 전화번호는 직접 열어 확인한 것만 넣는다. 고친 뒤 `checkedDate`를 바꾼다. AI에게는 `name`, `org`, `summary`만 넘어가므로, 요약에 쓴 숫자가 곧 AI가 쓸 수 있는 비용 기준이다.
