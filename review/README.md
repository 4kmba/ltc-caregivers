# 돌봄수첩 검수 페이지

유정민, 백민경, 한수연이 `app/content/`의 내용(할 일 카드, 질문과 답, 돌봄 방식, FAQ, 자료)을 나눠 검수할 때 쓰는 정적 웹페이지입니다. JSON 파일을 직접 읽지 않고, 휴대폰에서도 카드 모양으로 보며 판정과 메모를 남길 수 있게 만들었습니다. 제품 화면이 아니라 팀 내부 도구입니다.

주소: <https://4kmba.github.io/ltc-caregivers/review/> (GitHub Pages, `main` 브랜치 맨 위 폴더)

## 쓰는 법

1. 페이지 위에서 이름을 고릅니다. 맡은 것만 나옵니다.
2. 카드, 돌봄 방식, FAQ는 "괜찮아요" 또는 "고칠 곳 있어요"를 누르고 메모를 남깁니다. 카드의 답마다 "이 답에 고칠 곳 있음"을 눌러 따로 메모할 수 있고, 카드가 나올 상황이 이상하면 상황을 바꿔 표시합니다.
3. 자료는 원문을 열어 체크 항목을 모두 확인해야 "확인했어요"를 누를 수 있습니다. 누른 날짜가 확인 날짜로 남습니다.
4. 결과 화면의 **댓글 복사**를 눌러 자기 검수 이슈에 붙입니다. 중간에 여러 번 올려도 됩니다.

판정과 메모는 그 브라우저의 localStorage에만 저장됩니다. 다른 기기로 옮기려면 결과 화면의 "기록 파일 저장"과 "불러오기"를 씁니다.

## 파일

| 파일 | 내용 |
|---|---|
| `assignments.json` | 누가 어떤 카드, 방식, FAQ, 자료를 맡는지와 각자의 이슈 번호 |
| `index.html`, `review.js`, `review.css` | 페이지. `../app/content/*.json`을 읽기만 하고 고치지 않습니다 |

담당을 바꾸려면 `assignments.json`만 고쳐 PR을 올리면 됩니다. 내용 파일이 바뀌면 페이지는 새 내용을 그대로 보여 줍니다.

## 결과 옮기기

댓글 끝의 "기록용 데이터"에 확인한 자료 목록이 `{ "source", "by", "date" }` 형식으로 들어 있습니다. 이 값을 `app/content/sources.json`의 해당 자료 `checks`에 더하면 두 사람 확인이 기록됩니다. 고칠 곳은 내용 파일을 고치는 PR로 따로 반영합니다.

## 로컬에서 보기

저장소 맨 위 폴더에서 정적 서버를 띄우고 `/review/`로 들어갑니다. 파일을 더블클릭해 `file://`로 열면 브라우저가 JSON 읽기를 막습니다.

```bash
python3 -m http.server 4310
```

브라우저에서 <http://localhost:4310/review/>를 엽니다.
