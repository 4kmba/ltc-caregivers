# Team 10 (4K) — 장기요양 등급을 막 받은 가족을 위한 AI 서비스

KAIST 경영대학 **BIZ.69911 AI-Driven Business Evolution** (2026년 가을) 텀 프로젝트입니다.
Demo Day는 2026년 12월 19일입니다. 강의 전체 프로젝트 목록은 [강의 허브](https://github.com/yijisoo/kaist.biz.69911.projects/blob/main/2026-fall/PROJECTS.md)에 있습니다.

**팀 4K:** 김영균, 백민경, 유정민, 한수연

## 무엇을 하려는가

부모님이나 조부모님이 장기요양 등급을 막 받은 가족 보호자는 짧은 기간에 재가센터, 복지용구, 요양 서비스에 관한 결정을 한꺼번에 내립니다. 우리는 이 시기에 보호자가 겪는 문제 가운데 AI로 풀기에 알맞은 것을 찾아 제품으로 만듭니다.

현재 가설은 **복지용구 세컨드 오피니언**입니다. 복지용구사업소가 제안한 품목 리스트를 판매 이해관계 없이 검토해, 품목별로 "지금 필요 / 나중에 / 불필요"를 이유와 함께 알려주고, 잘 알려지지 않은 공공 자원으로 연결하는 서비스입니다. 자세한 정의는 [docs/PROJECT.md](docs/PROJECT.md)에 있습니다.

다만 방향은 아직 열어 두고 있습니다. 설문과 인터뷰로 보호자가 겪는 여러 문제를 탐색한 뒤, 그중에서 문제가 분명하고 AI가 실제로 도움이 되는 것을 고를 계획입니다. 가설이 바뀌면 이 문서와 `docs/`를 함께 고칩니다.
