# 심청이 그림 자리

B5 담당이 심청이 그림 파일을 넣는 폴더입니다. 화면 코드는 고치지 않아도 됩니다. 파일을 넣으면 바로 보이고, 파일이 없으면 그림 자리가 숨겨집니다.

화면은 `<img data-slot="simcheong" src="/img/simcheong/<이름>.png" alt="">`로 그림을 부릅니다. 그림은 꾸밈용이라 `alt`를 비워 두었고, 화면 낭독기는 읽지 않습니다.

## 파일 이름 규칙

| 파일 | 나오는 곳 |
|---|---|
| `default.png` | 표지(첫 화면), 수첩 페이지를 만드는 동안 보이는 "정리하는 중" 화면 |

- 이름은 영어 소문자와 `-`만 씁니다. 형식은 PNG입니다.
- 화면마다 다른 그림을 쓰고 싶으면 `cover.png`처럼 새 이름으로 넣고, 어느 화면에 쓸지 화면 담당자에게 알려 주세요. 코드에서 `ctx.simcheong("cover")`로 바꾸면 됩니다.
- 화면에는 가로 8rem(약 128px)까지만 보입니다. 휴대폰 화면에서도 선명하도록 가로 256px 정도로 저장하고, 파일 하나가 200KB를 넘지 않게 해 주세요.
- 배경은 투명하게 둡니다. 표지는 노랑, 속지는 흰색(어두운 화면에서는 먹색)이라 배경이 있으면 어색하게 보입니다.
- 서버가 외부 주소의 그림을 막으므로(CSP) 그림은 반드시 이 폴더에 넣습니다.
